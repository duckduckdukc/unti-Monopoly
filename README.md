# 职场人：锅来！

一款原生 HTML、CSS、JavaScript 制作的轻量躲避小游戏。玩家要在职场道路上左右移动，躲开甩锅、埋雷、天降任务等障碍。

## 当前玩法

- 主角是一名 22 岁、刚步入职场的年轻人。
- 现实游玩 1 分钟对应 3 个工作年；顶部持续显示“工作第 X 年 · 第 X 月”。
- 职业时间连续推进，跨月和跨年都不会打断游戏。
- 每工作 3 年自动建立一次缓存记录，只提示保存成功，不暂停游戏。
- 前进速度从 210 px/s 起步，每工作一年增加 18 px/s，在第 15 年达到 480 px/s 并封顶。
- 前 6 年道路前方有两名持续前进的前辈；两人的速度随工龄下降，系统持续记录其与主角的垂直距离，前辈甲会在第 6 年后被赶超。
- 当前事件包括天降大锅、前辈埋雷、前辈甩锅、天降任务和杂活。前辈事件会先播放对应动作，再从 NPC 所在位置产生障碍。
- 体力上限为 100；每次碰撞扣 34 点，体力归零后游戏结束。
- 点击右上角暂停按钮，或按空格、Esc、P，可暂停/继续。
- 暂停期间职业时间、速度、NPC 和障碍动画全部冻结；主动暂停和离开页面时也会保存，下次打开可点击“继续存档”。
- 电脑使用 ← → 或 A/D 移动；手机使用左右滑动。

## 运行方式

直接双击 `index.html` 即可运行。也可以在项目目录启动本地服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 目录结构

- `index.html`：页面结构和游戏界面
- `css/game.css`：画面与组件样式
- `js/config.js`：职业时间、体力、速度、前辈和障碍配置
- `js/game.js`：连续职业时间轴、主循环、暂停与存档
- `js/player.js`：角色移动与输入控制
- `js/npc.js`：前辈状态、速度、垂直距离和动作
- `js/obstacle.js`：五类事件的生成和移动
- `js/collision.js`：碰撞检测
- `js/ui.js`：界面状态和提示
- `开发记录.md`：版本变更与后续计划

## 常用修改入口

最常调整的数值集中在 `js/config.js`，文件内已经为每个字段加入中文注释：

- 时间换算、缓存间隔和速度巅峰年份：`GameConfig.career`
- 初始速度、每年增速、巅峰速度和事件频率：`GameConfig.game`
- 初始血量、碰撞伤害、键盘移动速度：`GameConfig.player`
- 前辈初始距离、随机速度和速度衰减：`GameConfig.seniors`
- 三条跑道的位置：`GameConfig.lanes`
- 障碍物种类和碰撞提示名称：`GameConfig.obstacles`

其他常用入口：

- 时间推进、三年缓存点、暂停和存档逻辑：`js/game.js`
- 前辈距离和赶超逻辑：`js/npc.js`
- 年月、血条和结算文案：`js/ui.js`
- 人物和障碍物外观：`css/game.css`
- 页面结构和按钮文字：`index.html`

## 存档说明

存档保存在当前浏览器的 `localStorage` 中，不会上传。存档包含当前工龄、体力、主角位置、前进速度和两名前辈的实时距离；旧版按月存档会自动换算到新时间轴。清理浏览器站点数据会同时清除存档。
